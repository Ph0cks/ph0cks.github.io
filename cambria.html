cambria. makeup

This is a design for a fictional product. I was tasked with going out of my comfort zone with this project. The ideas expressed in makeup design other than vanity are, strength, elegance and beauty. To accent the modern woman I wanted to use a modern design style for this piece, a bold moniker, large type, and flat color. Larger abstracted type wraps around each of the packages with a white line gracefully flowing like a ribbon throughout the forms. The abstraction of the type causes elements to be subtle but create beautiful visual elements that really pull the viewers attention.
